LƯU TRỮ FILE

Snapshot 2 lớp: dữ liệu (QLTD/KD/TD) và báo cáo theo mốc thời gian. Backup, khôi phục, so sánh A vs B.

📊 2 loại archive🏷️ Gắn nhãn mốc📈 So sánh A vs B
📊TAB 1 — Lưu trữ Dữ liệu Backup DATA▶
  1. 1
    💾 Lưu trữ Dữ liệu Ngay
    Snapshot toàn bộ DATA nén LZ, lưu IndexedDB + tải .xlsx. Tên file: Data 25/04/2026 01:36.
  2. 2
    ⬆️ Khôi phục — Restore từ file .xlsx
    Import file .xlsx đã backup → ghi đè DATA. Cần xác nhận trước khi thực hiện.
⚠️ Sau reload trang, chỉ khôi phục được từ file .xlsx đã tải về — không dùng nút 🔄 trong danh sách.
📈TAB 2 — Lưu trữ Báo cáo & So sánh A vs B▶
  1. 1
    Lưu báo cáo + gắn nhãn mốc
    Nhãn: Đầu năm Đầu quý Đầu tháng Cuối tháng — tự động gợi ý theo ngày.
  2. 2
    📊 So sánh — chọn 2 snapshot A vs B
    Delta: tăng/giảm dư nợ, số KH mới/tất toán theo CBTD. Nút "🔄 Hoán đổi" để đổi A↔B.
💡 Quy trình: Lưu đầu mỗi tháng (gắn "Đầu tháng") → cuối tháng so sánh để theo dõi biến động.
🔄 TỰ ĐỘNG HÓA

AUTO-SYNC IPCAS

Tự động đọc file IPCAS theo lịch. File System Access API — chỉ cần cấp quyền 1 lần, không thao tác thủ công mỗi lần cập nhật.

⏱️ 5/10/15/30/60 phút🧠 Smart check khi file đổi🌐 Chrome/Edge 86+
🚀THIẾT LẬP LẦN ĐẦU (Chỉ làm 1 lần) Bắt buộc▶
  1. 1
    Click 🔄 Auto-Sync trên topbar → chọn file IPCAS
    Chọn file .xls/.xlsx từ máy. Hệ thống ghi nhớ file handle — lần sau tự đọc không cần chọn lại.
  2. 2
    Chọn khoảng thời gian + chế độ xử lý
    Ask — hỏi trước | Auto — tự động import | Notify — chỉ thông báo. Khuyến nghị: 15 phút + Ask.
  3. 3
    Bật toggle → Badge ON xuất hiện sidebar
    Countdown đếm ngược đến sync tiếp. Smart Check: bỏ qua nếu file chưa thay đổi.
⚠️ Chỉ hoạt động Chrome/Edge 86+. Firefox/Safari không hỗ trợ File System Access API.
